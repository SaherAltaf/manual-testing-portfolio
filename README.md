# Manual Testing Portfolio – Sauce Demo

Manual testing of [Sauce Demo](https://www.saucedemo.com), a demo online shop made for testing practice.

## What I Tested
Login, product list and sorting, product details, cart, checkout and logout.

## Files
| File | What's inside |
|---|---|
| [test-plan.md](test-plan.md) | Scope, approach and test environment |
| [test-cases.csv](test-cases.csv) | 20 test cases with steps, expected and actual results |
| [Issues](https://github.com/SaherAltaf/manual-testing-portfolio/issues) | Bug reports with steps and screenshots |

## Bug Report Format
Every bug is logged in the **Issues** tab with:
- **Title:** short summary of the problem
- **Steps to Reproduce**
- **Expected Result**
- **Actual Result**
- **Severity:** Critical / High / Medium / Low
- **Screenshot**
